# CRM_Mail-Inbox-Settings — Improve Inbox settings statuses UI

Задача: бокова панель зі станом автоматизацій скриньки виглядає слабко, не зрозуміло, як змінити опції,
«Налаштування» стоїть у списку папок, хоча папкою не є.

## Рішення (v2, після рев'ю)
- «Налаштування» прибрано зі списку папок → окремий рядок між папками та блоком автоматизації.
- Блок «Автоматизація Email 2/3» зі шкалою — лише перегляд: іконка, назва (16px) і під нею лейбл статусу.
  Один індикатор стану — лейбл статусу (без тоглерів).
- Клік по «Налаштування» або по рядку автоматизації відкриває налаштування скриньки (як на проді, у правій колонці)
  і підсвічує потрібний розділ.
- Зміни застосовуються лише після «Зберегти». Якщо щось вимикається — модалка підтвердження з переліком того,
  що перестане працювати (напр. «Передавати в чат-бот»).
- Права: без прав блок показує ті самі статуси, але без переходу в налаштування.

## Стани прототипу (панель справа внизу)
- Стан: усе вимкнено / частково / усе увімкнено
- Права: Адміністратор / Без прав

## Файли
- `index.html` — розмітка (DOM повторює прод: `.mailbox`, `.mailbox__list-folders`, `.thread`, `.blue-table`).
- `styles/prototype.css` — Part 1: стилі, зняті з проду; Part 2: новий блок і налаштування.
- `scripts/prototype.js` — стан, рендер блоку, налаштування, підтвердження, нативні тости (Noty).
