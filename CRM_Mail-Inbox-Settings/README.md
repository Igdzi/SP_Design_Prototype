# CRM_Mail-Inbox-Settings

Задача: **Improve Inbox settings statuses UI** — блок статусів автоматизацій поштової скриньки в CRM / Пошта.

## Що змінено відносно проду
- «Налаштування» лишається останнім пунктом списку папок (як на проді).
- Блок «Автоматизація CRM»: лічильник і прогрес «N з 3», рядки з іконкою, назвою, статусом (точка + текст) та перемикачем справа — все вирівняно по сітці.
- Для увімкнених автоматизацій видно деталі: воронка/статус і відповідальний (аватар + ім'я), посилання «Змінити» веде одразу до потрібного розділу налаштувань.
- NEW прив'язаний до назви (`sup.color-active`).

## Файли
- `index.html` — розмітка (DOM повторює прод: `.mailbox`, `.mailbox__list-folders`, `.thread`, `.blue-table`).
- `styles/prototype.css` — Part 1: стилі, зняті з проду; Part 2: новий блок.
- `scripts/prototype.js` — стан, перемикачі, налаштування скриньки в правій колонці, панель станів прототипу.
